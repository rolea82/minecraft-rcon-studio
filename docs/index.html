Administra tu servidor de Minecraft de forma visual y sin lag

Aplicación de escritorio nativa para gestionar reglas de juego, jugadores, mundo, consola en vivo y descargar versiones oficiales con un solo clic.

🚀 Inicio Rápido

La aplicación se distribuye como un archivo ejecutable autónomo (portable) que no necesita instalación de Node.js:

Opción 1: Ejecutable Portátil .EXE

Haz doble clic sobre Minecraft RCON Studio.exe en la carpeta de la aplicación. Se abrirá inmediatamente.

Opción 2: Desde el Código Fuente
npm install
npm start

⚙️ Cómo Configurar RCON en tu Servidor

Para conectar la interfaz a un servidor existente, asegúrate de tener estas 4 líneas en tu archivo server.properties: 

enable-rcon=true
rcon.port=25575
rcon.password=tu_contraseña_secreta
broadcast-rcon-to-ops=false
💡 Importante: Reinicia tu servidor tras editar server.properties para que el puerto RCON se abra.

📥 Descargador Oficial de Versiones (Nuevo en V2)

En la pestaña "Descargar Servidor" de la aplicación puedes instalar cualquier versión oficial de Mojang con un solo clic:

  • Desplegable de Versiones: Conectado a Mojang para descargar desde la 1.21.4 hasta versiones clásicas o snapshots.
  • Aceptación Automática del EULA: Crea eula.txt con eula=true.
  • Configuración Automática: Activa RCON con la contraseña que tú elijas en la pantalla.
  • Script start.bat: Genera el archivo de arranque con los GB de RAM seleccionados y flags optimizados de Java.
  • Arranque en 1 Clic: Pulsa Iniciar Servidor Ahora para abrir la consola de Minecraft de inmediato.

🛡️ Seguridad y Buenas Prácticas

Aislamiento y Protección: La aplicación utiliza aislamiento de contexto en Electron (contextIsolation: true, nodeIntegration: false), validación estricta contra ataques de salto de directorio (Path Traversal) y verificación de certificados SSL oficiales de Mojang.

⚠️ Advertencia de Red para Servidores Locales:

El protocolo RCON de Minecraft no cifra las comunicaciones por defecto. NUNCA abras el puerto 25575 en tu router hacia internet público. Si necesitas acceso fuera de casa, utiliza siempre una VPN privada (como Tailscale o WireGuard) o un túnel SSH seguro.
